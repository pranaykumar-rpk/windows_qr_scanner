## 1.0.0

- First stable release of `windows_qr_scanner`.
- Added full Dartdoc documentation across the public API and internal services.
- Exported `WindowsQrScannerState` and `WindowsQrScannerStatus` from the package entrypoint.

## 0.1.0

- Initial release of `windows_qr_scanner`.
- Added Windows-only QR scanning controller API.
- Added optional `WindowsQrScannerView` preview widget.
- Added frame throttling and duplicate prevention.
- Added clean architecture services for camera, frame processing, and ZXing decoding.
